# التقرير
KPIs: المتابعون (صافي)، الوصول، المشاهدات، معدل التفاعل = (إعجاب+تعليق+مشاركة)/مشاهدات، نقرات الاتصال/الملف، أفضل 3 منشورات، أسوأ منشور.
الشكل: ملخص 3 أسطر → جدول KPIs مقابل الأسبوع السابق → ماذا نجح/فشل → 3 توصيات.
لا تخترع أرقاماً؛ اذكر المصدر (Windsor/Metricool) والفترة.
