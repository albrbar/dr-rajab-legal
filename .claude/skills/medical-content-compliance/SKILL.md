# المراجعة الطبية
- [ ] المعلومة صحيحة ومتسقة مع الإرشادات (IWGDF) ولا تتجاوز الإنفوجرافيك المعتمد.
- [ ] لا وعود بالشفاء أو نسب نجاح غير موثقة («نعمل على تقليل خطر البتر» لا «نضمن»).
- [ ] لا تشخيص ولا أسماء أدوية أو جرعات.
- [ ] PRP مذكورة بصيغة «إذا رأى الطبيب ملاءمتها».
- [ ] لا بيانات مرضى ولا صور جروح في الإعلانات الممولة.
- [ ] لا مواعيد لمصحة الربيع قبل تأكيد المنسق، ولا أرقام/مواعيد لقرة العين والسلامة.
- [ ] لا تشخيص عن بُعد في الردود؛ «يحتاج فحص سريري».
- [ ] لا صور تكشف هوية مريض؛ صور الحالات بموافقة مكتوبة.
- [ ] المواعيد والأرقام مطابقة للجدول الرسمي في clinic-brand-facts (Notion)، وكل مكان برقمه.
- [ ] النص العربي داخل الصور سليم (انظر visual-qa-arabic-text).
النتيجة: «معتمد» أو قائمة تعديلات.
