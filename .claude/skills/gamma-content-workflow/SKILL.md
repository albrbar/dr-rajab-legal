# Gamma
- format:"social" للبوستات/الكاروسيل، "webpage" لصفحة الهبوط، "presentation" للعروض.
- textOptions.language:"ar"، والهوية في additionalInstructions (أزرق داكن وذهبي، شعار القدم).
- راجع ملفات موجودة أولاً (get_gammas) لتجنب التكرار.
- صدّر PNG للنشر، وطبّق visual-qa-arabic-text.
