# /grillme — النقاش قبل الإنتاج

## القواعد
1. **سؤال واحد فقط في كل رسالة**، بخط كبير وبلهجة بسيطة.
2. كل سؤال: 2–4 خيارات (أ/ب/ج/د) + توصيتك مع **رقم من البيانات** يبررها.
3. لا تنتقل للسؤال التالي قبل الجواب. لا تفترض الجواب.
4. اسأل حتى يُحسم كل بند: الجمهور، الهدف، الفكرة، الخطاف، النص (واللهجة حرفياً)، الشكل، الصور/الصوت، الدعوة للإجراء، المنصة، الموعد، المقياس.
5. بعد آخر سؤال: ملخص قرارات مرقّم ← «موافق؟». لا إنتاج قبل «موافق».
6. سجّل القرارات في `reports/<التاريخ>/grill-decisions.md`.

## ترتيب الأسئلة (للمنتج)
الجمهور → الهدف (متابعة/رسائل/وعي) → الموضوع → الخطاف (أول 1.5 ث) → النص سطراً سطراً → اللغة/اللهجة → الصورة/الفيديو/الصوت → الدعوة للإجراء → المنصات → الموعد → كيف نقيس النجاح.
