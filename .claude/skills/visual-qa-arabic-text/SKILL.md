# فحص الصور
- اقرأ كل نص عربي في الصورة؛ الذكاء الاصطناعي يولد كلاماً بلا معنى (مثال مرصود: «اذ) تقرع ذلك راحال الحسبي...» في 08 و09).
- تحقق أن الرقم والمواعيد تطابق الجدول الرسمي (رقم المكان الصحيح)، وأن الشعار هو الرسمي. أي صورة عليها مواعيد/أرقام قديمة = مرفوضة.
- تحقق من المقاس: 1:1 أو 4:5 فيسبوك/إنستغرام، 9:16 تيك توك/ستوري.
- الحكم: صالح / يحتاج تعديل (حدد العنصر) / مرفوض.
